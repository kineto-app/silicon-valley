The industry says, we built

It's the whole lifecycle, not a coding agent

A software factory is the full loop: collect signals, prioritise, orchestrate, execute, validate, test in production, iterate. "Generating code, writing code, that's the easy part."

Tereza Tížková, Factory
How we built it

Signals come in from alerts, customer tickets, tracker issues delegated to a bot and Kinetik's own problem reports. Dinesh builds, Gilfoyle ships through a gate and keeps watching prod after, and the verdict lands back on the customer's ticket. A ticket is Done only when it's on prod, not when it's merged.

Verification, not generation, is the constraint

Generation is cheap and scales; review doesn't. Validators should check code they did not write, and autonomy should grow only as far as verification keeps up.

Addy Osmani · Tereza Tížková, Factory
How we built it

No PR before proof: Dinesh brings up a preview env for his branch, runs QA himself and reports what he poked and what he saw. Then someone else checks: Jian-Yang reviews every PR, bots' included, and each finding is fixed or rebutted in writing; Gilfoyle, not the author, verifies the rollout through a gate written in code.

Lit, not dark: humans where a wrong call is expensive

"A healthy AI software factory isn't a factory with the humans removed." Some go fully dark anyway: StrongDM's charter says code must not be written or reviewed by humans.

LaunchDarkly · StrongDM
How we built it

We run lit on purpose. People press four kinds of buttons: words to a customer, money, merge, and a deploy the gate isn't sure about. Everything between them is delegated. New autonomy is earned: Donald's refunds ran in shadow mode until humans agreed with him often enough, then were switched on one action at a time.

The field moves monthly

A bought platform freezes last quarter's idea of an agent. Ours swapped a runtime with one pull request.

The valuable part isn't for sale

Runtimes are a commodity. The gates, guardrails and who presses which button are your process. No vendor ships that, so you write it anyway.

You need to see inside

When an agent touches prod or money, you want to read every line between the model and the side effect.

The honest price

You own the upgrades, the security and the on-call for your on-call bot. For a startup, that's a good trade.
